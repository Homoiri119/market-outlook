# 指数の暴落買いルールブック v1(2026-11-12)

[legend_traders_2026-11-11.md](legend_traders_2026-11-11.md) の結論を、そのまま実行できるルールにしたもの。個別株を機械的なルールで選んでもTOPIXに勝てなかった(6.6節)ので、売買するのは**指数ETFだけ**。BNF・cisの「市場全体がパニックの時に買う」と、テスタの「局面で張り方を変える」「計画外のナンピンはしない」を組み合わせる。

一般的なルールの検証であり、個別の投資助言ではない。

---

## 1. ルール(これだけを守る)

### 1.1 前提

| 項目 | 決めごと |
|---|---|
| 売買するもの | 日経225連動ETF(例:1321)。個別株・信用取引・レバレッジETFは使わない |
| 判断に使う値 | **日経平均の終値**(15:30以降に確定した値) |
| 注文 | 判断した翌営業日の**引成**(終値で約定) |
| 資金の単位 | この口座の資金を**3等分**し、1つを「1ユニット」とする。保有は最大3ユニット(=資金の100%) |
| 毎日の作業 | 引け後に下の3つの判定をし、翌日の目標ユニット数を決めて、差の分だけ引成で売買する |

### 1.2 3つの判定

| | 名前 | 買う条件(当日終値で判定) | 手仕舞いの条件 | 量 |
|---|---|---|---|---|
| **T** | 上昇局面 | 終値 > 200日移動平均 | 終値 ≤ 200日移動平均 | 3ユニット |
| **B** | 短期の売られすぎ | 25日移動平均からの乖離が**−10%以下**になった(1回の下落局面で1回だけ。乖離が0%以上に戻ったら次に備える) | 終値が25日移動平均以上に戻った日の翌日、または買ってから20営業日 | 1ユニット |
| **C** | 大きな調整 | 250日高値から**−15%以下**になった(1回だけ。高値から−5%以内に戻ったら次に備える) | 買ってから120営業日(約半年)。途中で売らない | 1ユニット |

### 1.3 目標ユニット数

```
目標ユニット数 = max( Tがオンなら3、オフなら0 ,  保有中のBとCの数 )   ※上限3
```

- 上昇局面(T)では、常に3ユニット(全額)を持つ。BとCが出ても上乗せはしない。
- 200日線を割ったらTの分を売る。ただし、保有期間中のBとCの分は持ち続ける。
- BとCは、それぞれ決まった日数が来るまで機械的に持つ。

### 1.4 資金管理のルール

| ルール | 中身 | 由来 |
|---|---|---|
| 上限 | 資金の100%まで。信用取引・レバレッジは使わない | — |
| ナンピン | BとCで計画された買い下がり以外はしない。「もっと下がったから追加」は禁止 | テスタ |
| 損切り | **価格での損切りはしない**。BとCは日数で手仕舞う(検証では−15%の損切りを入れると年率が1.7%→0.6%に下がった) | 検証の結果 |
| 停止ルール | この口座が高値から**−45%**(過去最悪の−34%の約1.3倍)まで下がったら、新しい売買を止めてルールを見直す | テスタの「ドローダウンで立て直す」 |
| ルールの変更 | 年1回まで。変更理由を書き、過去の売買はやり直さない | — |
| 記録 | 判定の結果と約定を毎日記録する | — |

## 2. 想定される成績(日経平均、2000〜2026年)

条件:当日の終値で判定し、翌日の終値で売買。往復コスト0.1%。配当は含まない(配当を入れると、常に持つ「買って持つだけ」の方が年0.5%前後有利になる)。現金の利息はゼロ。

| | 年率 | 最大下落 | シャープ | 平均の投資比率 |
|---|---|---|---|---|
| 買って持つだけ | +4.5% | **−66%** | 0.30 | 100% |
| Tだけ(200日線) | +2.9% | −41% | 0.26 | 60% |
| BとCだけ(暴落時だけ買う) | +1.7% | −18% | 0.29 | 11% |
| **このルール(T+B+C)** | **+4.7%** | **−34%** | **0.36** | 67% |

期間を分けた場合:

| 期間 | 買って持つだけ | このルール |
|---|---|---|
| 2000〜2012年(下げ相場) | −4.5%/年、最大−66% | **+1.7%/年**、最大−33% |
| 2013〜2026年(上げ相場) | **+13.4%/年**、最大−32% | +7.6%/年、最大−34% |

売買の内訳(2000〜2026年):

| | 回数 | 勝率 | 1回の平均 | 最悪 |
|---|---|---|---|---|
| B(乖離−10%) | 19 | 74% | +4.0% | −12.5% |
| C(高値から−15%) | 17 | 65% | +3.3% | −14.0% |

### このルールの性格(正直に)

- **大きな下げを半分にするルール**であって、指数に勝つルールではない。26年間の年率は「買って持つだけ」とほぼ同じで、最大下落は−66%から−34%になる。
- 大きく下げた年に強い。2008年は−42%に対して−5.5%、2001年は−24%に対して+2.1%、2002年は−19%に対して−3.4%。
- **上げ相場では負ける**。2013〜2026年は年+13.4%に対して+7.6%で、勝った年は全体の35%しかない。200日線を割るたびに降りて、戻ったあとに買い直すので、上昇の一部を取り逃がす。
- 一番苦しかったのは2018年1月〜2020年3月(−34%)。200日線の出入りで何度も損をしたあと、コロナの急落が来た。

## 3. パラメータの頑健性

条件を前後に動かしても、成績はほとんど変わらない。基準の値は範囲の中ほどにあり、一番良い値を選んだわけではない。

| 動かした条件 | 年率 | 最大下落 |
|---|---|---|
| 基準(200日線・乖離−10%・高値から−15%・120日) | +4.7% | −34% |
| 移動平均150日 / 250日 | +5.8% / +5.5% | −32% / −33% |
| 乖離−8% / −12% | +4.6% / +4.1% | −35% / −36% |
| 高値から−12% / −18% / −20% | +5.2% / +5.3% / +4.9% | −36% / −33% / −36% |
| Cの保有60日 / 250日 | +4.5% / +4.6% | −35% / −43% |
| **全14通りの範囲** | **+4.1〜+5.8%** | **−32〜−43%** |

## 4. 採用しなかったもの

| 案 | 採用しない理由 |
|---|---|
| 1日で−4%下げた日に買う(cis) | 翌日の終値で買うと効果がなかった(外しても年率は同じで、最大下落は小さくなる)。効くのはその日の引けで買えた場合だけで、毎日14:50〜15:25に判断する必要がある |
| 価格での損切り(−15%) | 暴落後の戻りを取り逃がす。年率1.7%→0.6% |
| ドローダウンでロットを半分にする | 指数の逆張りでは、一番安い所で量を減らすことになる。年率1.7%→1.0%。代わりに「−45%で停止して見直す」にした |
| 常に50〜70%持ち、残りを暴落用の現金にする | 年率2.9〜3.3%で、最大下落も−49〜−58%と大きい。このルールより劣る |
| BとCを1回で全額にする | 最初の下げで全額になり、もっと深い下げで買えない。年率−0.7% |
| 個別株の順張り・逆張り | 生存者バイアスを除くと、どれもTOPIXに勝てなかった(6.6節) |

## 5. 毎日の手順

1. 15:30以降に、日経平均の終値・25日移動平均・200日移動平均・250日高値を確認する。
2. T:終値が200日線より上か下か。
3. B:乖離が−10%以下になったか(待機中の場合だけ)。保有中なら、25日線を回復したか・20日経ったか。
4. C:高値から−15%以下になったか(待機中の場合だけ)。保有中なら、120日経ったか。
5. 目標ユニット数を計算し、今の保有との差を、翌営業日に引成で注文する。
6. 判定の結果・注文・約定を記録する。
