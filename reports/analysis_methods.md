## 1. 全体像

```
米国市場・日経先物(yfinance) ─┐
                                ├─→ 寄り付き予想 ─┐
J-Quants 日足・銘柄マスタ ──────┼─→ 個別銘柄分析 ─┼─→ 買い候補の選定 ─→ Discord通知
Google News RSS ────────────────┴─→ ニュース分類 ─┘          │
                                                                └─→ ペーパー運用(実績)
検証系:指数/セクター/個別株バックテスト、IPO検証、戦略検証、要因分析
```

毎朝の処理(GitHub Actions「Morning Routine」)は、テーマニュース → 個別銘柄分析 → 寄り付き予想+買い候補 → 実績更新 の順に1ジョブで実行する。

## 2. データと共通ルール

### 2.1 データソース

| 用途 | ソース | 内容 |
|---|---|---|
| 米国市場 | yfinance | S&P500(^GSPC)、NASDAQ(^IXIC)、NYダウ(^DJI)、VIX(^VIX)、ドル円(USDJPY=X) |
| 追加の夜間指標 | yfinance | SOX(^SOX)、米10年金利(^TNX)、WTI原油(CL=F) |
| 日経平均・先物 | yfinance | 日経平均(^N225)、CME日経先物(NKD=F を優先、NIY=F を予備) |
| 個別株 | J-Quants V2 | 銘柄マスタ(/equities/master)、分割調整済み日足(/equities/bars/daily)、TOPIX(/indices/bars/daily/topix)、日付指定の全銘柄日足(IPO検出用) |
| ニュース | Google News RSS | テーマ・銘柄名で検索した見出し |

### 2.2 共通ルール

- **確定したバーだけを使う**:予想する日(東京の取引日 D)より前に確定した終値だけを使う。寄り付き後に処理が動いても、取引途中のバーを拾わないようにして、いつ実行しても同じ結果になるようにする。
- **日付は日本時間**:GitHub Actions は UTC で動くため、予想日は JST の日付で決める。
- **株式分割の補正**:J-Quants・yfinance とも過去の株価を分割で遡って調整する。記録した建値と現在の価格系列の前日終値が20%超ずれていたら分割とみなし、価格系列を建値の基準に揃え直す。
- **データの鮮度**:個別分析は当日に作られたものだけを使い、各銘柄の最新日足が前営業日のものでなければ買い候補から外す。
- **先読みをしない**:バックテストやシミュレーションは、その時点で得られた情報だけで判断する(指標は過去データのみから計算、学習は検証日より前のデータのみ)。

## 3. 寄り付き予想(朝のアウトルック)

### 3.1 目的変数

```
寄り付きギャップ(D) = 日経平均の始値(D) ÷ 前営業日の終値 − 1
```

### 3.2 予想式

```
予想寄り = 0.9 × 先物ギャップ + 0.1 × 回帰モデルの予測
先物ギャップ = 前夜に確定したCME日経先物の終値 ÷ 日経平均の前営業日終値 − 1
```

- **先物ギャップ**:先物は米国市場の引けを既に織り込んでいるため、寄り付きの主な手がかりになる(要因分析で寄りの値動きの約7割を説明)。前夜の取引が確定した日足の終値を使い、確定値が無い場合だけ実行時点の5分足を使う。
- **回帰モデル**:S&P500の騰落率、VIXの変化、ドル円の騰落率を説明変数とする線形回帰。直近1年分のデータで毎朝学習し直す。
- **重み**:当初0.7(先物)/0.3(回帰)。要因分析の結果(方向的中 0.7で73.2%、0.9で74.7%)を受けて0.9/0.1に変更。

### 3.3 方向・レンジ・相場環境

| 項目 | 判定方法 |
|---|---|
| 方向 | 予想寄りが +0.8%以上=強上昇、+0.2%以上=上昇、±0.2%以内=横ばい、−0.2%以下=下落、−0.8%以下=強下落 |
| 予想レンジ | 予想寄り ± 直近20日の寄りギャップの標準偏差(データ不足時は±0.4%) |
| VIXの水準 | 15未満=落ち着き、20未満=注意、30未満=警戒、30以上=恐怖 |
| トレンド | 日経平均の25日移動平均と、最新終値の乖離率 |

### 3.4 「主な背景」の要約

寄りへの影響が大きい順に、一定以上動いたものだけを並べる(要因分析の結果に基づく)。

1. 日経先物ギャップ(常に表示。±0.2%未満は「ほぼ横ばい」)
2. SOX(±1%以上)
3. NASDAQ・S&P500(±0.5%以上)
4. VIX(±1pt以上)

ドル円・米金利・原油は、一晩の寄りへの影響がほぼ無いため表示しない。どれも動いていなければ「米国株は小動き」と書く。

### 3.5 精度の追跡

- 毎朝の予想を履歴に保存し、翌日以降に実際の寄りを記録して的中を判定する。
- **的中の判定**:予想と実際の符号が一致したら的中。±0.15%以内は横ばいとして扱う。
- **実際の寄りは確定した日足から取る**:当日分は朝に記録せず、過去日は毎回確定値で上書きする(取引途中のデータで誤記録した分も自動で直る)。
- 表示する指標:直近20日の方向的中率と平均絶対誤差。
- 監査用に、計算した時刻・寄り付き後の計算だったか・先物の取得方法も保存する。

## 4. 指数バックテスト

寄り付き予想の考え方が過去に通用したかを、日経平均で検証する。

- **期間**:約6年(2021-03〜)。
- **方法**:ウォークフォワード(拡張ウィンドウ)。各検証日について、その日より前のデータだけで回帰モデルを学習し、その日の寄りギャップを予想する。最初の120日は学習専用。
- **評価**:
  - 寄りギャップの方向的中率と平均絶対誤差(予想が主張していることそのもの)。
  - **売買の損益は寄り→引けで測る**。寄りギャップ自体は、買える時点で既に起きているため取れない。以前は終値→終値で計算して取れないギャップまで含め、結果が大きく膨らんでいたので改めた。
  - 戦略は3つ:予想が上なら寄りで買って引けで売る(ロング/ノーポジ)、予想の向きに売買(ロング/ショート)、保有し続ける(比較用)。年別にも集計。

どの業種が米国市場のシグナルで予想しやすいかを調べる。

## 6. 個別銘柄分析

### 6.1 対象

大型株(TOPIX Core30+Large70)とウォッチリストの銘柄。J-Quants の分割調整済み日足を使い、契約の取得期間に合わせて1,400日(約3.8年)→1,000日→600日の順に取得を試す。

### 6.2 指標

| 指標 | 定義 |
|---|---|
| 移動平均 | 5日・25日・75日の単純移動平均、25日線からの乖離率 |
| MACD | 12日EMA − 26日EMA、シグナル=MACDの9日EMA、ヒストグラム=差 |
| RSI | 14日(値上がり幅と値下がり幅の単純平均の比) |
| ATR | 14日の真の値幅(高値−安値、前日終値との差の大きい方)の平均 |
| ボリンジャーバンド | 20日平均 ± 2σ |
| 高値圏 | 直近250日の高値・安値、高値からの乖離 |
| 直近の節目 | 直近10日の安値(支持)・高値(抵抗) |
| 出来高 | 当日出来高 ÷ 25日平均 |

### 6.3 方向の判定(点数制)

| 条件 | 点数 |
|---|---|
| 株価 > 25日線 > 75日線(逆の並びは減点) | ±2 |
| 上記以外で株価が25日線の上/下 | ±1 |
| 株価 > 5日線 > 25日線(逆は減点) | ±1 |
| MACDヒストグラムがプラス/マイナス | ±1 |
| RSI 55以上 / 45以下 | ±1 |
| 直近250日の高値から3%以内 | +1 |

合計3点以上=買い、1〜2点=やや買い、−1〜−2点=やや売り、−3点以下=売り、0点=中立。
RSI 70以上は「買われすぎ」、30以下は「売られすぎ」として点数には入れず、エントリーのタイミング判定(押し目待ちなど)に使う。

### 6.4 売買の価格

| 項目 | 計算 |
|---|---|
| 損切り | 建値 − 1.5×ATR |
| 利確 | 建値 + 2.5×ATR(リスクリワード 1:1.67) |
| トレール | 高値 − 2.5×ATR を追いかけて損切りを切り上げる |
| 押し目買い | 25日線を指値の建値とし、そこから損切り・利確を計算 |

日足・週足・月足のチャートと、各銘柄の最新日足の日付(データの鮮度確認用)も出力する。

## 7. 個別株の戦略バックテスト

個別銘柄分析の買いシグナルが、過去に利益を生んだかを検証する。

- **対象**:大型株、約3.5年。
- **エントリー**:「終値 > 25日線 > 75日線」かつ「MACDヒストグラム > 0」に新たになった日の終値で買う。
- **比較する3つの設定**:
  - 基本:損切り −1.5ATR、利確 +2.5ATR(最長40日)
  - 地合いフィルタ:TOPIXが200日線より上の時だけ買う
  - トレール:地合いフィルタ+高値−2.5ATRの追随損切り、利確なし(最長60日)
- **評価はR倍数**(損益 ÷ 最初の損切り幅)で、株数や価格に依存しない形にする。勝率、期待値(平均R)、プロフィットファクター(総利益÷総損失)、最大ドローダウン、資金曲線(累積R)。

## 8. 買い候補の選定

### 8.1 点数

```
選定スコア = 個別銘柄分析の点数 + 業種の追い風 × 250 + 地合いの加点 + ニュースの点数(±3に制限)
```

- **業種の追い風**:前夜の米国指標を17業種に割り当てた目安(例:電機・精密=SOXとNASDAQの平均、銀行=米金利の変化、エネルギー資源=WTI)。+0.4%の追い風で約+1点。
- **地合いの加点**:予想が上昇系なら+1、下落系なら−1。VIXが「恐怖」なら−1、「警戒」なら−0.5を追加。

### 8.2 手順

1. 鮮度チェックで古いデータの銘柄を外す(2.2参照)。
2. 方向が「買い」「やや買い」の銘柄に選定スコアを付け、上位10銘柄を選ぶ。
3. 各銘柄のニュースを取得し、**重大な悪材料**(下方修正・不祥事など、悪材料で重み3)がある銘柄を除外する。
4. ニュースの点数を足して並べ直し、上位5銘柄を通知する。
5. 下落予想の日は「新規は見送り推奨」と表示する。

通知する売買ルールは、戦略検証の結果に基づき「寄りで買う/損切り・利確は寄り値から計算/最長5営業日で手仕舞い」。

## 9. ニュース分析

- テーマ(例:半導体・AI、防衛、インバウンド)や銘柄名で Google News RSS を検索し、直近数日の見出しを取得する。テーマはWeb画面から編集できる。
- **見出しの分類**:キーワードで出来事の種類に分け、良い/悪い材料の向きと重要度(1〜3)を付ける。

| 重要度 | 良い材料 | 悪い材料 |
|---|---|---|
| 3 | 業績の上方修正 | 業績の下方修正、不祥事・法務 |
| 2 | 最高益・増益、株主還元、受注・提携・M&A | 減益・赤字、減配・無配、増資・希薄化 |
| 1 | 格上げ・目標株価の引き上げ、新製品・好材料 | 格下げ・目標株価の引き下げ、急落・安値 |

- **ニュースの点数** = Σ(向き × 重要度)。プラスなら好材料、マイナスなら悪材料。

## 10. IPOセカンダリー投資の検証

IPOの抽選に頼らず、上場後に市場で買う手法の損益を検証する。

- **IPOの検出**:J-Quants に上場日の項目が無いため、検証期間の最初の約12営業日に取引のあった銘柄を一括取得し、銘柄マスタにあってそこに無い銘柄を「期間中に上場した銘柄」の候補とする。最初の日足が期間の開始から30日以上後なら、その日を上場日とみなす。
- **対象**:個別株だけ。33業種が空欄の銘柄や、市場区分・銘柄名にETF・ETN・REIT・インフラファンド・投資法人を含むものは除外する。キオクシアは数年に一度の外れ値として除外する。
- **手法**:上場日の始値(初値)で買い、0・1・3・5・10・20営業日後の終値で売る(0は当日の引け)。
- **評価**:保有日数ごとの件数・勝率・平均・中央値・最大・最小。外れ値に引っ張られにくい中央値を重視する。1件30万円を投資した場合の累積損益(上場順)も描く。

## 11. 推奨銘柄のペーパー運用(実績トラッキング)

毎朝の買い候補を「推奨どおりに売買していたら」という前提で記録し、成績を追う。

### 11.1 記録と計算

- 推奨した全銘柄を建玉として記録する。保有中の銘柄は重複して建てない。
- **毎回、全建玉を最初から計算し直す**ため、ルールを変えると過去の建玉にも反映される。
- **建値は推奨日の寄り値**。損切り(−1.5ATR)と利確(+2.5ATR)を寄り値から置き直す。ATRは推奨時の値を使う。
- **約定は現実的に**:窓を開けて損切り・利確を飛び越えた日は、寄り値で約定したとみなす。同じ日に損切りと利確の両方に触れた場合は損切りを優先する(保守的)。
- 株式分割は自動補正(2.2参照)。

### 11.2 決済方式(3つを並行して計算)

| 方式 | 内容 |
|---|---|
| 5日決済(推奨) | 損切り・利確、または買った日から5営業日後の引けで手仕舞い |
| 固定利確 | 損切り・利確のみ、期限なし |
| トレール | 高値−一定幅の損切りを切り上げ、利確なし(前日までの高値で更新) |

### 11.3 株数と資金

| 方式 | 株数 | 資金の基準 |
|---|---|---|
| リスク1% | 資金100万円の1%(1万円)÷ 損切り幅。1株単位(単元未満株を想定) | 100万円 |
| 現物100株 | 全銘柄100株 | 期間中に同時に持った100株分の合計額の最大値を、1万円単位で切り上げた額(投下資金が資金を超えないように) |

100株固定は値の張る銘柄の比重が大きくなるため、実力を測る基準はリスク1%とする。

### 11.4 表示

評価額の推移、確定損益と含み損益、勝率、投下資金、推奨日の地合い(予想の方向)。地合いで絞り込み(下落予想日を除く)もできる。

## 12. 戦略検証(反実仮想シミュレーション)

実績が想定どおりか、別のルールなら儲かったかを検証する。手順書は [strategy_review_prompt.md](strategy_review_prompt.md)。

### 12.1 問い

| # | 内容 |
|---|---|
| Q1 | 寄り付き予想の的中率(予想の方向別) |
| Q2 | 実績とバックテストの比較(勝率・平均R・PF) |
| Q3 | エントリーの前提(前日終値で買えたか、推奨日の寄りの窓、当日中の損切り到達) |
| Q4 | 地合い(推奨日の予想・実際の寄り)別の成績 |
| Q5 | 決済ルールを変えた場合の成績 |
| Q6 | 含み益・含み損の最大値と、決済後の値動き |
| Q7 | 銘柄選定の偏り(繰り返し推奨、業種) |

### 12.2 手法

- **株価は yfinance の日足**で、同じ推奨を別のルールで再現する。
- **決済ルールのグリッド**:損切り幅 {1.0, 1.5, 2.0, 2.5}×ATR と、決済方法 {固定利確 1.0/1.5/2.5/3.5ATR、トレール 1.5/2.5ATR、3/5/10日で決済、利確+最長5日、利確+建値ストップ、トレール+最長5日} の組み合わせ、計52通り。
- **約定**:窓開けは寄り値で約定。トレールは前日までの高値で更新(当日の高値で切り上げてから当日の安値で判定する楽観的な計算を避ける)。
- **成績はR倍数**(1%リスク換算。1R=1万円)。
- **過学習の対策**:期間を前半と後半に分け、**両方で上位に入る設定だけを推奨**する。
- **含み益・含み損**:保有中の最大含み益と最大含み損をATR単位で測る。利確後10日の追加上昇と、損切り後10日以内に建値まで戻った割合も見る。
- **判断のルール**:20件未満の区分からは結論を出さない(参考扱い)。手数料は往復約0.2%(1件あたり約0.05R)として結論で差し引く。

## 13. 寄り付きの要因分析

何が寄り付きの上げ下げを決めているかを調べる。

- **期間**:2021-01〜2026-10、約1,400営業日。
- **時間の揃え方**:東京の取引日 D とその前の取引日 P について、各指標は「P より前の最後の終値」から「D より前の最後の終値」までの変化を使う(=前日の東京引け後から当日の寄りまでに終わった米国側の動き)。先物は P の日経平均終値との比較。東京が休場の日もこれで正しく揃う。
- **単独の関係**:各指標と寄りギャップの相関、説明力(相関の2乗)、実際に±0.2%超動いた日に向きが一致した割合。
- **同時に入れた場合**:全指標を標準化して回帰し、係数(1σ動いた時の影響)を比べる。先物だけ/米国指標だけ/全部の説明力も比べる。
- **大きく動いた日の前夜**:寄りギャップを5区分(大幅高・小幅高・横ばい・小幅安・大幅安)に分け、前夜の各指標の平均を比べる。
- **予想の作り方の比較**:先物だけ/回帰だけ/先物0.7+回帰0.3/先物0.9+回帰0.1 の的中率と誤差。
- **寄り付き後との関係**:先物ギャップと寄り→引けの値動きの相関。
- **直近の外れ方の分類**:「先物は当たっていたのに予想が横ばい/逆向き」「実際は小動き」「先物も外れた(米国引け後のニュース)」などに分ける。

## 16. 制約と注意点

- **手数料・スリッページ・税金は計算に入れていない**(戦略検証の結論では1件あたり約0.05Rとして差し引いた)。
- **サンプルが小さい**:推奨の実績は約7週間・76件。同じ日に複数銘柄を建てるため、独立したサンプルはさらに少ない。
- **相場局面への依存**:戦略検証では前半はどの設定もマイナス、後半はほぼプラスと、ルールより相場の影響が大きかった。
- **日足だけの判定**:同じ日に損切りと利確の両方に触れた場合、どちらが先かは分からないため損切りを優先している。
- **米国指標の時刻のずれ**:ドル円は日足の区切りの都合で、寄りの直前までの動きを一部含む。
- **回帰モデルの目的変数**:寄り付き予想の回帰は、寄りギャップではなく翌日の終値→終値の騰落で学習している。先物の重みを0.9にしたため影響は小さく、作り直しは見送っている。
- **過学習**:多くの設定から最良を選ぶと良く見えやすい。前半・後半の両方で上位の設定だけを採用している。
