# 相場から退場する人・悪いトレードの整理(2026-11-12)

[legend_traders_2026-11-11.md](legend_traders_2026-11-11.md) の逆側の調査。勝っている人の真似は「銘柄選び」が再現できなかったので、負ける人の行動を集めて「やらないことリスト」を作る。

対象:岐阜暴威(負けを公開し続けている個人投資家)のインタビュー記事、ネット上の失敗談・事件、個人投資家の売買を調べた学術研究、このリポジトリの検証結果。

> 本人の発言はすべて自己申告で、第三者の検証はない。一般的な行動の研究であり、個別の投資助言ではない。

---

## 1. 結論

1. **退場(資金をほぼ失う)の原因は、ほぼ1つに集約される。「レバレッジや集中で一度に大きく張った状態で、損切りしない」**。岐阜暴威は、ライブドア・ショック、リーマン・ショック、チャイナ・ショック、コロナ・ショックの4回、資金がほぼゼロになった。いずれも信用取引・高レバレッジのFX・先物で全力に近い量を持っていた時。
2. **ゆっくり負ける「悪いトレード」の原因は、売買の回数とコスト**。台湾の全取引データでは、個人の損失の約2/3は取引コストで、ほぼすべてが成行などの「急ぐ注文」から生まれていた。よく売買する人ほど成績が悪い(年11.4%、市場は17.9%)。
3. **心理のパターンは共通している**:利益はすぐ確定して損は抱える、損切りラインを動かす、負けを取り返そうとして量を増やす、勝ちが続くと慎重さを失う、「一発逆転」が目的になっている。
4. **このリポジトリの検証でも、負けるトレードは同じ形をしていた**。急騰した株に飛び乗る(売買代金急増の順張り:年−25.7%、+10%の窓に乗る:年−29.2%)、すでに一番強い株を選ぶ(どの順張りでもランダムに選ぶより悪化)。
5. 勝つ方法は再現できなかったが、**負ける方法は再現性が高い**。だから「やらないこと」を守るだけで、多くの退場は避けられる(7章)。

### 2.2 本人が語る負けパターン

| パターン | 本人の発言・事例 |
|---|---|
| 一発逆転が目的 | ジェイコム事件を見て始めた。「今すぐ」勝ちたいという我慢のなさを自覚している |
| 全力・高レバレッジ | 信用の二階建て、FXで100万通貨、先物10枚。資金がゼロになった4回はすべてこの状態 |
| 損切りラインを動かす | ラインに近づくと「ちょっと待てよ」と理由をつけて動かす。「根拠を超えた途端に判断が崩れる」 |
| 利益は早く、損は抱える | 利益は少額で確定し、含み損は強制決済まで耐える。その結果、底で切ることになり「逆神」に見える |
| 小さく抜いて大きく負ける | 「10円抜き」(2015年)と「10pips抜き」(2020年)はどちらも、小さな利益の積み重ねが1回の損失で消えた |
| 勝った後に崩れる | 勝ちが続くと気が緩み、「ここまで勝っているから持ち直せる」と次の勝負を重ねる。資産が2,800万円前後まで来ると「もっと上へ」と無理をして、短期間で大きく負けるのを約3年繰り返している |
| 取り返そうとする | 負けた額が大きいほど「これ以上負けたくない」で冷静さを失う。2025年は焦って被害を広げた |
| 負けるとマイナー商品へ | 主要な商品で負けると、香港指数・ココア・天然ガス・マイナー通貨など取引の少ない商品に移る |
| 売買しすぎ | 24時間取引できるFXを「チャンスに見えて実はピンチ」「罠」と表現。ルールは「逆指値を入れたらチャートを見ない」だが、1日に約500回見る |
| イベントの持ち越し | 2022年、米CPIの発表前に円売りを持ち越し、予想外の結果で含み損320万円 |
| 専業になった直後に負ける | 2013年(4,600万円で退職)と2022年(8か月連勝で退職)の2回とも、直後に大きく負けている |
| 根拠のない自信 | 負けた後も「来月は勝てる」と思い続けていた。アドバイスは、損をすれば相手のせい、得をすれば自分の実力と考えてしまうので聞かない |

精神科医の名越康文氏は対談で、本人の中に「100億円を目指す別の自分」がいて、それが損失の実感を薄めていると分析している。提案は「資産の半分は確実に残し、残りの半分で勝負する」。

本人が実際にやっている対処:負けが続きそうな時は、証券口座から強制的に出金し、レバレッジをかけられない額だけを残す。読者には「『熱くなりすぎる』ところは絶対にまねしない方がいい」と言い、相場に向いていないと感じたら積立投資に切り替えるのも選択肢だとしている。

## 3. ネット上の事例・事件から見る退場のパターン

| パターン | 事例 | 何が起きるか |
|---|---|---|
| **信用の二階建て** | 2006年ライブドア・ショック(岐阜暴威もここで退場)。現物株を担保に、同じ株を信用で買う | 株価が下がると、担保の価値と信用で買った株の両方が同時に下がる。保証金維持率が20%を割ると追証。払えなければ証券会社が銘柄を選ばずに強制決済する |
| **ナンピン → 信用でさらにナンピン** | 割安と判断して買い下がり、「これ以上安くなるはずがない」と信用で追加した直後に相場全体が急落。狼狽売りした価格が底で、その後大きく上昇(マネーポストの体験談、約1,500万円の損失) | 損が一番大きくなった所で、強制的にまたは心が折れて売る |
| **市場全体の急落** | 2024年8月5日:日経平均が1日で4,451円安(史上最大の下げ幅)、翌日は史上最大の上げ幅。信用残が急減し「売らされた」 | 追証で強制的に売らされた人は、翌日の戻りを取れない。信用評価損益率は−20%前後が追証の水準で、底の目安ともされる |
| **商品性を理解していない** | 2018年2月:VIX(恐怖指数)の逆に動くETN(2049)が1日で約8割下がり、早期償還・上場廃止。説明が不十分だったとして紛争解決のあっせん申立てが255件に。米国の同種の商品XIVも償還 | 「普段は少しずつ儲かる」商品が、1日で元本の大半を失う |
| **想定外の急変** | 2015年1月スイスフラン・ショック:中央銀行が上限を撤廃し、ユーロ/フランが短時間で約30%動いた。海外のFX業者2社が破綻 | ロスカットが間に合わず、口座の残高以上の損失が出る。逆指値を置いていた人は損失を小さく抑えられた例もある |
| **成功体験による過信** | 2024年初めの造船株の急騰で「自分には才能がある」と考え、勉強しなくなる。相場が軟調になると失敗が続き、「次こそは」と資金を入れて退場(マネーポスト) | 上げ相場での勝ちを自分の実力と勘違いする |

## 4. 学術研究:個人投資家はどう負けるか

| 研究 | 対象 | 結果 |
|---|---|---|
| Barber & Odean (2000) "Trading Is Hazardous to Your Wealth" | 米国の6万6,465世帯(1991〜1996年) | 最もよく売買する世帯は年11.4%、市場は17.9%。売買前の成績(銘柄選び)はあまり変わらず、**差は売買の回数とコスト**。原因は自信過剰 |
| Barber, Lee, Liu & Odean (2009) | 台湾の全投資家の全取引(1995〜1999年) | 個人全体で年3.8%の損失(GDPの2.2%)。**損失の約2/3は取引コスト**、ほぼすべてが成行などの急ぐ注文から。機関投資家は年+1.5% |
| Barber, Lee, Liu & Odean(台湾のデイトレーダー) | 年に約36万〜45万人 | 大半のデイトレーダーが損をしている。前年の上位(全体の1%未満)だけが、翌年も安定して勝つ |
| Chague, De-Losso & Giovannetti (2019) "Day Trading for a Living?" | ブラジルで2013〜2015年に指数先物のデイトレードを始めた1万9,646人 | 300日以上続けた人の**97%が損失**。最低賃金以上を稼いだのは1.1%。続けても上達した証拠はない |
| Odean (1998)(処分効果) | 米国の個人投資家 | 利益の出ている株を、損している株の約1.5倍売りやすい(利益は早く確定し、損は抱える) |

岐阜暴威の負けパターン(売買しすぎ、利益は早く損は抱える、上達しない)は、研究で見つかった個人の平均的な負け方とほぼ同じ。

## 5. このリポジトリの検証で確かめた「悪いトレード」

[legend_backtest_2026-11-12.md](legend_backtest_2026-11-12.md) の生存者バイアスなしの検証(全上場銘柄、2024〜2026年)から。基準はTOPIXの年+17.6%、全銘柄の均等保有の年+13.0%。

| 悪いトレード | 検証したルール | 結果(年率、同時10銘柄の口座) |
|---|---|---|
| 急騰している株に飛び乗る | 売買代金が急増して値上がりした株を買う | **−25.7%**(最大下落−64%) |
| ニュースで窓を開けて上がった株に乗る | +10%以上の窓開けの後に買う | **−29.2%**(最大下落−69%) |
| 一番強い株を選ぶ | 順張りのシグナルが多い日に、相対強度が高い順に買う | どの手法でもランダムに選ぶより悪化(例:52週高値ブレイク +13.6% → −6.8%) |
| 下がった個別株を、下がったという理由で買う | 250日高値から−15%の個別株を120日持つ | −4.0%(1件あたりTOPIXより−4.0%) |
| 指数の暴落買いに価格の損切りを入れる | −15%で損切り | 年率1.7% → 0.6%(底で切って戻りを取り逃がす) |

1〜2行目は、岐阜暴威の「急騰に飛び乗る」「マイナー商品に移る」、ネットの「造船株で才能があると勘違い」と同じ形。

## 6. 退場する人・悪いトレードをする人の分類

| タイプ | 特徴 | 典型的な終わり方 |
|---|---|---|
| **一発逆転型** | 少ない資金を短期間で大きくしたい。レバレッジ・信用・集中を使う | 市場全体の急落で一度にほぼゼロ(退場) |
| **損切りできない型** | 含み損を抱え、ラインを動かし、ナンピンする | 強制決済か、一番安い所で心が折れて売る |
| **コツコツドカン型** | 小さな利益を何度も取り、1回の大損で全部失う | 「10円抜き」「10pips抜き」の結末 |
| **取り返し型** | 負けた後に量や回数を増やす。マイナーな商品に移る | 負けが加速する |
| **過信型** | 上げ相場での勝ちを実力と思う。勝った直後に専業になる・量を増やす | 相場が変わった直後に大きく負ける |
| **売買しすぎ型** | 1日に何十回も売買し、チャートを何百回も見る | コストと急ぐ注文で、ゆっくり確実に減る |
| **商品を理解しない型** | 仕組みを知らずにレバレッジ商品・ETNを買う | 1日で元本の大半を失う |

## 7. やらないことリスト(退場パターン → 防ぐルール)

| やらないこと | 防ぐ退場パターン | 根拠 |
|---|---|---|
| 信用取引・レバレッジ・二階建てを使わない | 一発逆転型、市場全体の急落 | 岐阜暴威がゼロになった4回すべて。2024年8月の追証 |
| 予定外のナンピンをしない(計画した買い下がりはよい) | 損切りできない型 | ナンピン → 信用 → 狼狽売りの体験談。テスタのルール |
| 損切りや手仕舞いのルールを、注文を出す前に決め、途中で動かさない | 損切りできない型 | 岐阜暴威「ラインを動かす」 |
| 負けた後に量や回数を増やさない。主要な商品以外に移らない | 取り返し型 | 岐阜暴威の2025年、マイナー商品への移行 |
| 勝ちが続いた後に、量を増やしたり専業になったりしない | 過信型 | 岐阜暴威の2013年・2022年 |
| 売買の回数を減らす。急ぐ注文(成行での飛び乗り)をしない | 売買しすぎ型 | Barber & Odean、台湾の研究 |
| 急騰した株・窓を開けた株に飛び乗らない | 一発逆転型 | 検証で年−26%、−29% |
| 仕組みを説明できない商品は買わない | 商品を理解しない型 | VIXインバースETNの償還 |
| 口座には、失ってもよい額だけを置く | すべて | 岐阜暴威の「強制出金」。名越氏の「半分は確実に残す」 |

今の[プレイブック](index_crash_rulebook.md)(TOPIX ETFだけ・レバレッジなし・計画外のナンピンなし・手仕舞いは日数で決める・売買は年に数回)は、このリストの大半を満たしている。
